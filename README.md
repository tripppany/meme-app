# Генератор Мемов (Telegram Mini App)

Современное веб-приложение на **React + TypeScript + Vite + Tailwind CSS** для создания, редактирования, модерации и публикации мемов в Telegram-чатах и беседах.

## 🚀 Возможности

- **Интерактивный холст (HTML5 Canvas)**:
  - Drag & Drop перемещение надписей и изображений мышью и пальцем на смартфонах.
  - Настройка шрифта (размер, заливка, контур).
  - Наложение стикеров и дополнительных фотографий на шаблон.
  - Быстрое выравнивание (вверх, центр, вниз).
- **Библиотека шаблонов**:
  - Встроенные шаблоны мемов в SVG.
  - Модальное окно выбора шаблона.
  - Возможность загрузки любого изображения с устройства в качестве фона.
- **Публичная галерея сообщества**:
  - Просмотр всех одобренных мемов.
  - Указание автора мема (`@username`).
  - Скачивание мемов в формате PNG высокого качества.
- **Панель модерации (Админка)**:
  - Очередь предложенных мемов с функциями «Одобрить» и «Отклонить».
  - Управление шаблонами (добавление новых шаблонов с картинкой и названием, удаление).
  - Управление Telegram ID администраторов с защитой главного администратора (`502413224`).
  - Секретный вход в режим администратора (5 кликов по логотипу «ураа мемы»).
- **Интеграция с Telegram WebApp SDK**:
  - Автоматическая адаптация интерфейса к размерам окна Telegram (`ready`, `expand`).
  - Автоматическое определение пользователя Telegram для подписи авторства мемов.

## 🛠️ Стек технологий

- **React 18**
- **TypeScript**
- **Vite 6**
- **Tailwind CSS v4**
- **Font Awesome 6**
- **Telegram WebApp SDK**

## 📦 Запуск проекта

```bash
# Установка зависимостей
npm install

# Запуск локального сервера разработки
npm run dev

# Сборка проекта
npm run build
```
